# رصد اخبار برق منطقه‌ای یزد

ابزاری که هر چند ساعت یک‌بار به‌طور خودکار چند خبرگزاری معتبر ایرانی رو برای کلمات کلیدی مشخص (مثلاً «برق»، «یزد») بررسی می‌کنه و نتایج رو توی یک وب‌آپ ساده نمایش می‌ده.

## اجزای پروژه

- `keywords.json` — لیست کلمات کلیدی برای جستجو. هر وقت خواستی کلمه اضافه/حذف کنی، همین فایل رو ویرایش کن.
- `sources.json` — لیست خبرگزاری‌ها و آدرس RSS اون‌ها. اگه یه منبع جدید خواستی اضافه کنی، فقط یک آبجکت `{"name": "...", "url": "..."}` بهش اضافه کن.
- `scripts/fetch-news.js` — اسکریپتی که فیدها رو می‌خونه، فیلتر می‌کنه و نتایج رو توی `data/results.json` می‌نویسه.
- `.github/workflows/fetch-news.yml` — کاری که هر ۳ ساعت خودش اسکریپت رو اجرا می‌کنه (دقیقاً مثل پروژه تولدها).
- `index.html` — وب‌آپی که نتایج رو نشون می‌ده؛ فیلتر بر اساس کلمه کلیدی و جستجوی متنی داره.

## راه‌اندازی (شبیه پروژه تولدها)

1. یک ریپازیتوری جدید توی گیت‌هاب بساز و همه‌ی این فایل‌ها رو توش آپلود کن.
2. برو به تب **Settings → Pages** و Source رو روی شاخه `main` (پوشه `/root`) بذار تا سایت فعال بشه. آدرس سایتت می‌شه چیزی شبیه:
   `https://USERNAME.github.io/REPO-NAME/`
3. برو به تب **Actions**، روی workflow «بروزرسانی رصد اخبار» بزن روی **Run workflow** تا یک‌بار دستی اجرا بشه و `data/results.json` پر بشه.
4. از این به بعد هر ۳ ساعت خودش اجرا می‌شه و نتیجه رو commit می‌کنه. اگه خواستی سرعت بیشتر یا کمتر بشه، عدد `*/3` توی فایل workflow رو عوض کن (مثلاً `*/1` برای هر ساعت).

## نکات مهم

- **دقت جستجو:** فیلتر فعلی بر اساس وجود دقیق عبارت توی عنوان/خلاصه خبره (نه هوش مصنوعی). اگه خواستی دقیق‌تر بشه یا خلاصه‌سازی هوشمند با AI هم اضافه بشه (مثل ابزارهای قبلیت که از Groq/Gemini استفاده می‌کردن)، بگو تا اضافه کنم.
- **اگه یک منبع خطا داد:** پایین صفحه‌ی وب‌آپ وضعیت هر منبع (سبز = سالم، قرمز = خطا) نشون داده می‌شه. آدرس‌های RSS گاهی توسط سایت‌ها تغییر می‌کنه؛ کافیه آدرس جدید رو توی `sources.json` جایگزین کنی.
- **حجم داده:** نتایج قدیمی‌تر از ۴۵ روز خودش پاک می‌شه تا فایل بزرگ نشه (قابل تنظیم توی `scripts/fetch-news.js`، متغیر `MAX_AGE_DAYS`).
- این نسخه فقط **نمایش** می‌ده. اگه بعداً خواستی خروجی مستقیم به کانال بله/ایتا هم ارسال بشه (مثل سیستم تولدها)، می‌تونیم دقیقاً همون الگو رو بهش اضافه کنیم.
